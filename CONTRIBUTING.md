# Contributing Guidelines

Thank you for your interest in contributing to this project!

---

## How to Contribute

This is primarily a portfolio/educational project, but contributions are welcome in the following areas:

### 1. **Documentation Improvements**
- Fix typos or clarify instructions
- Add examples or use cases
- Translate documentation

### 2. **Bug Reports**
- Use GitHub Issues
- Include error messages
- Provide steps to reproduce

### 3. **Feature Suggestions**
- Open a GitHub Issue first
- Describe the use case
- Explain expected behavior

### 4. **Code Contributions**
- Fork the repository
- Create a feature branch
- Write clear commit messages
- Submit a Pull Request

---

## Development Setup
```bash
# Clone repository
git clone https://github.com/yourusername/rag-system.git
cd rag-system

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set up AWS credentials
aws configure
```

---

## Code Standards

- **Python**: Follow PEP 8
- **Comments**: Write clear, concise comments
- **Functions**: Keep functions small and focused
- **Error Handling**: Always include try-catch blocks
- **Testing**: Add tests for new features

---

## Pull Request Process

1. **Update documentation** if needed
2. **Test thoroughly** on your AWS account
3. **Ensure no secrets** are committed
4. **Update CHANGELOG** (if applicable)
5. **Request review** from maintainer

---

## Questions?

Open a GitHub Issue or reach out via email.
