## Data Flow

Request Flow:
1. Client → API Gateway (HTTPS POST)
2. API Gateway → Lambda (Event trigger)
3. Lambda → Department Detector (Keyword analysis)
4. Lambda → Knowledge Base (Retrieve context)
5. Lambda → Bedrock (LLM inference)
6. Bedrock → Lambda (Generated answer)
7. Lambda → API Gateway (Formatted response)
8. API Gateway → Client (JSON response)


## Component Details

### API Gateway
- **Type**: REST API
- **Region**: us-east-1
- **Endpoint**: `/prod/query`
- **Methods**: POST
- **CORS**: Enabled (Access-Control-Allow-Origin: *)

### Lambda Function
- **Runtime**: Python 3.11
- **Memory**: 512 MB
- **Timeout**: 30 seconds
- **Concurrency**: Default (1000)
- **Cold Start**: ~500-700ms
- **Warm Start**: ~200-300ms

### AWS Bedrock
- **Model**: meta.llama3-70b-instruct-v1:0
- **Max Tokens**: 1024
- **Temperature**: 0.1
- **Region**: us-east-1

### IAM Permissions
```json
{
  "Lambda Execution Role": {
    "AWSLambdaBasicExecutionRole": "CloudWatch Logs",

    "AmazonS3ReadOnlyAccess": "S3 read access (future)"
  }
```

## Security

-  HTTPS only (TLS 1.2+)
-  IAM role-based access
-  No hardcoded credentials
-  Environment variables for config
-  API keys (future)
-  Rate limiting (future)
