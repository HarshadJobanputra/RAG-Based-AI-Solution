# AWS Deployment Guide - RAG Company Policies

Complete guide to deploy the RAG system to AWS Lambda with production-grade configuration.

##  Deployment Overview

### Architecture
```
Internet
    ↓
API Gateway (REST API)
    ↓
Lambda Function (Container)
    ├── Memory: 2048 MB
    ├── Timeout: 60s
    └── Container: Python 3.11 + FAISS + LangChain
    ↓
AWS Bedrock (Titan + Llama 3)
    ↓
S3 Bucket (FAISS Index)
```

### Components to Deploy

1. **S3 Bucket** - Store FAISS index
2. **ECR Repository** - Store Docker container
3. **Lambda Function** - Run RAG system
4. **IAM Roles** - Permissions
5. **API Gateway** - HTTP endpoint (optional)
6. **CloudWatch** - Logging and monitoring

##  Step 10: Cost Optimization

### Configure Reserved Concurrency
```bash
# Limit concurrent executions (cost control)
aws lambda put-function-concurrency \
    --function-name TechCorpRAGFunction-FAISS \
    --reserved-concurrent-executions 10
```

### Enable Lambda Function URL (Alternative to API Gateway)

**Free alternative to API Gateway:**
```bash
# Create function URL
aws lambda create-function-url-config \
    --function-name TechCorpRAGFunction-FAISS \
    --auth-type NONE \
    --cors '{
        "AllowOrigins": ["*"],
        "AllowMethods": ["POST"],
        "AllowHeaders": ["Content-Type"],
        "MaxAge": 300
    }' \
    --region us-east-1

# Get function URL
aws lambda get-function-url-config \
    --function-name TechCorpRAGFunction-FAISS \
    --region us-east-1 \
    --query 'FunctionUrl' \
    --output text
```

**Savings:** €3.50/month (no API Gateway charges)

### Set Up Lifecycle Policies
```bash
# S3 lifecycle policy (archive old indexes)
aws s3api put-bucket-lifecycle-configuration \
    --bucket techcorp-faiss-index-${AWS_ACCOUNT_ID} \
    --lifecycle-configuration '{
        "Rules": [{
            "Id": "ArchiveOldIndexes",
            "Status": "Enabled",
            "Transitions": [{
                "Days": 30,
                "StorageClass": "STANDARD_IA"
            }],
            "NoncurrentVersionTransitions": [{
                "NoncurrentDays": 7,
                "StorageClass": "GLACIER"
            }]
        }]
    }'
```

### Update Lambda Code
```bash
# Rebuild image
docker build --platform linux/amd64 -t techcorp-rag-lambda:latest .

# Tag with version
docker tag techcorp-rag-lambda:latest ${ECR_URI}:v1.1

docker push ${ECR_URI}:v1.1

# Update Lambda
aws lambda update-function-code \
    --function-name TechCorpRAGFunction-FAISS \
    --image-uri ${ECR_URI}:v1.1
```

##  Troubleshooting

### Issue 1: Lambda timeout

**Symptoms:** Function times out after 60 seconds

**Solution:**
```bash
# Increase timeout
aws lambda update-function-configuration \
    --function-name TechCorpRAGFunction-FAISS \
    --timeout 90
```

### Issue 2: Out of memory

**Symptoms:** "Runtime exited with error: signal: killed"

**Solution:**
```bash
# Increase memory
aws lambda update-function-configuration \
    --function-name TechCorpRAGFunction-FAISS \
    --memory-size 3008
```

### Issue 3: FAISS index not found

**Symptoms:** "FileNotFoundError: index.faiss"

**Solution:**
```bash
# Verify S3 files
aws s3 ls s3://techcorp-faiss-index-${AWS_ACCOUNT_ID}/faiss_index/

# Check permissions
aws iam get-role-policy \
    --role-name TechCorpRAGLambdaRole \
    --policy-name TechCorpRAGPolicy
```

### Issue 4: Cold start too slow

**Symptoms:** First request takes 10+ seconds

**Solutions:**

**Option A: Provisioned Concurrency**
```bash
aws lambda put-provisioned-concurrency-config \
    --function-name TechCorpRAGFunction-FAISS \
    --provisioned-concurrent-executions 1 \
    --qualifier $LATEST
```
**Cost:** +€10/month, but guaranteed warm start

**Option B: Keep-Warm Script**
```bash
# Create EventBridge rule (ping every 5 minutes)
aws events put-rule \
    --name KeepLambdaWarm \
    --schedule-expression "rate(5 minutes)"

aws events put-targets \
    --rule KeepLambdaWarm \
    --targets "Id"="1","Arn"="arn:aws:lambda:us-east-1:${AWS_ACCOUNT_ID}:function:TechCorpRAGFunction-FAISS"

aws lambda add-permission \
    --function-name TechCorpRAGFunction-FAISS \
    --statement-id AllowEventBridge \
    --action lambda:InvokeFunction \
    --principal events.amazonaws.com
```
**Cost:** Minimal (~€0.20/month)

## 📈 Performance Monitoring

### View Metrics
```bash
# Get function metrics
aws cloudwatch get-metric-statistics \
    --namespace AWS/Lambda \
    --metric-name Duration \
    --dimensions Name=FunctionName,Value=TechCorpRAGFunction-FAISS \
    --start-time $(date -u -d '1 hour ago' +%Y-%m-%dT%H:%M:%S) \
    --end-time $(date -u +%Y-%m-%dT%H:%M:%S) \
```

##  Production Best Practices

### Security

1. **Enable VPC:** Run Lambda in private subnet
2. **Secrets Manager:** Store API keys securely
3. **WAF:** Add Web Application Firewall to API Gateway
4. **API Keys:** Require authentication

### Reliability

1. **Multi-region:** Deploy to us-west-2 as backup
2. **Versioning:** Use Lambda versions and aliases
3. **Canary deployments:** Gradual traffic shifting
4. **Health checks:** Automated testing

### Performance

1. **Connection pooling:** Reuse Bedrock connections
2. **Caching:** Add ElastiCache for repeated queries
3. **Async processing:** Use SQS for batch queries
4. **CDN:** CloudFront for API responses
